Security architecture

QSHIELD brings evidence-led security to quantum software: circuit analysis, equivalence verification, dependency auditing, runtime policy, and release provenance in one toolkit.

Built for quantum software teams. Local-first analysis with optional cloud AI assistance.

What QSHIELD protects

  • Circuit integrity: source, gate structure, parameters, and expected behavior.
  • Supply-chain integrity: dependency declarations, installed package metadata, and analysis configuration.
  • Analysis environment: the QSHIELD process, its dependencies, local files, and CI configuration.
  • External services: quantum providers, package registries, and optional AI services connect through explicit configuration.

With the local Workbench, the browser sends circuit input to the Workbench server for analysis. Optional AI features use cloud services: triage sends finding summaries, while speech and report commands send their supplied audio, text, or report to the configured provider. Use AI assistance for cloud workflows where that data handling fits your team.

Coverage

T1 · Gate tamperingStructural analysis flags inserted, substituted, and perturbed gates. Exact and formal comparison validate circuit behavior across supported methods.
T2 · Information leakageAncilla, measurement, and information-flow analysis surface leakage risks with gate locations and remediation context.
T3 · Supply-chain compromiseDependency auditing flags risky pins, typosquatting indicators, and known advisories. Release wheels, source archives, and GHCR images carry build-provenance attestations, and two independent builds are compared before publication. Circuit manifests support Ed25519 signatures for signed provenance.
T4 · Circuit confidentialityLocal-first analysis keeps circuit review in your environment and produces integrity evidence for engineering workflows.

Operating guidance

  • Parsers enforce size, complexity, and time budgets and report malformed input explicitly.
  • Findings include locations, confidence, and remediation context for engineering review.
  • The Workbench runs on loopback by default; shared deployments use network restrictions with an authenticated TLS proxy and --allow-remote.
  • Core analysis runs locally and offline; AI assistance is opt-in for cloud workflows.

Evaluation

  • Benchmarked on 417 bundled fixtures: 202 clean and 215 malicious.
  • Release artifacts are verified with GitHub build provenance before installation.
  • Reports include SARIF, JSON, HTML, and PDF outputs for CI and team review.

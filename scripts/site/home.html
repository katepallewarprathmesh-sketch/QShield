What QSHIELD does

From circuit analysis
to reviewable evidence.

Independent checks bring structural analysis, comparison, policy evaluation, and supply-chain review together in a clear workflow for engineering teams.

01 / SCAN

Static circuit analysis

Analyze circuit structure, known threat signatures, information flow, dead logic, and software dependencies across supported circuit inputs.

02 / COMPARE

Check circuit intent

Compare a trusted circuit with a candidate using exact methods and proof-oriented ZX-calculus.

03 / PROBE

Test finding robustness

Apply semantics-preserving camouflage transforms and check whether findings survive common evasive changes.

04 / GOVERN

Policy as code

Score reviewable hygiene policies on the bundled corpus. Compare detection and clean-circuit match rates before adopting a rule.

05 / AUDIT

Quantum dependency review

Review package requirements for name anomalies, version signals, and known advisories as part of the circuit supply chain.

06 / EXTEND

Sandboxed detector plugins

Run explicitly selected WASI detectors in a sandbox and bring their evidence into your review workflow.

How it works

A readable path from source to decision.

Use the CLI in CI, the browser Workbench for interactive review, or the Python API in your own tooling.

01 — INGEST

Parse circuit source

Read supported quantum circuit formats into a normalized representation.

02 — ANALYZE

Run independent checks

Structural analysis, signatures, policy rules, and package auditing.

03 — VERIFY

Compare and validate

Equivalence and robustness checks validate circuit behavior across supported methods.

04 — REVIEW

Support team decisions

Findings include locations and remediation context; use SARIF, JSON, HTML, or PDF reports.

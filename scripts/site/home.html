What QSHIELD does

From suspicious gates
to reviewable evidence.

Different checks answer different questions. QSHIELD keeps their evidence distinct, reports uncertainty honestly, and does not claim that a clean scan proves a circuit is safe.

01 / SCAN

Static circuit analysis

Detect suspicious structure, known threat signatures, information leakage, dead logic, and supply-chain risks across supported circuit inputs.

02 / COMPARE

Check circuit intent

Compare a trusted circuit with a candidate using exact methods where feasible and proof-oriented ZX-calculus on supported fragments.

03 / PROBE

Test finding robustness

Apply semantics-preserving camouflage transforms and check whether findings survive common evasive changes.

04 / GOVERN

Policy as code

Score reviewable hygiene policies on the bundled corpus. See both true-positive and false-positive counts before adopting a rule.

05 / AUDIT

Quantum dependency review

Inspect package requirements for suspicious names, risky versions, and known advisories as part of the circuit supply chain.

06 / EXTEND

Sandboxed detector plugins

Run explicitly selected WASI detectors with resource limits. Plugin output is separate evidence and does not silently change core verdicts.

How it works

A readable path from source to decision.

Use the CLI in CI, the browser Workbench for interactive review, or the Python API in your own tooling.

01 — INGEST

Parse without executing

Read supported quantum circuit formats into a normalized representation.

02 — ANALYZE

Run independent checks

Structural analysis, signatures, policy rules, and package auditing.

03 — VERIFY

Test claims within limits

Equivalence or robustness checks return a qualified verdict, including unknown where needed.

04 — REVIEW

Keep a human in the loop

Findings include locations and remediation context; use SARIF, JSON, HTML, or PDF reports.

Trust & limits

Evidence, not a safety certificate.

QSHIELD is designed to help reviewers find and investigate known classes of risk—not to replace security review or prove that quantum software is honest.

  • Fixture-corpus metrics are not field rates.
  • Formal equivalence is available only for supported fragments.
  • No QPU, device SDK, or hardware acceptance path.
  • Community signature pack stays empty by design.
  • Browser Workbench analysis runs locally; the optional AI service is separate and advisory.

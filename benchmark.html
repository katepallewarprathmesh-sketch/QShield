Reproduce or challenge

The corpus is public, so the detectors are public too. Rerunning the scorer should reproduce the numbers above exactly:

pip install -e '.[dev]'
python benchmarks/benchmark.py

To submit an evasion that QSHIELD misses, attach a .qasm file, the threat family it should map to, and the scorer output showing flagged: false. Accepted submissions become a labelled fixture in the next corpus version, and the gap is recorded in the changelog. Corpus versions are immutable.

Protocol

  • Corpus, labels, and generator ship in the repository; the corpus digest is recorded in every result.
  • Scoring rule is fixed in advance and applied uniformly to every circuit.
  • Missed circuits and false positives are listed in the result document.
  • CI fails if the stored results drift from a fresh run.
  • Every number describes this corpus and this QSHIELD version.

Read the full protocol in benchmarks/benchmark-v1.md, the design in Security architecture, or return to the Workbench.
